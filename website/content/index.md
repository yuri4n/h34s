# Scala handlers. Nuxt applications.

[AI SLOP]{.ai-slop} Written with Codex. Human review pending.

h34s is an unpublished Scala.js toolbox for Nuxt/Nitro. The current development slice offers ordinary ZIO handlers, application-owned service layers, Skunk database access, scoped streaming, and Scala source maps.

Start with [the getting-started guide](/guide/getting-started), [adopt h34s in an existing project](/guide/adoption), or explore [handlers and environments](/guide/handlers).

A first-class Kyo integration, published artifacts, automatic route and type generation, and production application packaging are planned. Read [the current project status](/reference/status) before choosing a production setup.
