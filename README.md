# h34s

A Scala.js toolbox for Nuxt/Nitro server handlers, with developer experience as a first-class requirement.

This repository is being bootstrapped. The recovered playground will be reviewed in a draft pull request. It is not a released or verified MVP.

The planned direction is a Kyo core, an optional ZIO integration, and first-class sbt/Nix development and packaging support. These integrations are not implemented in this bootstrap commit.
